# Free Home Decoration Design

## Goal

Let each learner create a distinct home instead of filling a predetermined layout.

## Fixed and movable structure

- Fixed yard: house, boundary fence, entrance path and base ground.
- Fixed interior: walls, doors, ceiling, tatami geometry and tokonoma architecture.
- Movable starter yard items: two basic trees and several rocks. All can be moved or stored; `Restore starter layout` returns them without repurchasing.
- Movable rewards: plants, flower patches, stones, lanterns, water features, fence pieces, paths, furniture, storage, screens, lighting and display objects.
- Tokonoma accepts scrolls, flowers, pottery, plants and seasonal ornaments, not ordinary furniture.

## Placement

- Use a dense invisible placement grid rather than eight visible beds or six named furniture slots.
- Placement targets appear only while an item is selected.
- Each movable instance stores position and quarter-turn rotation. Invalid overlap leaves state unchanged.
- Move, rotate and store are reversible. Stored starter items remain owned.
- Clearing the yard stores every movable object and produces a genuinely empty yard.

## Visual foundation

- Yard background is restrained gravel and moss with open negative space; no baked-in removable trees, beds, rocks or decorations.
- Interior is an open tatami room with usable wall, floor, shelf, sill and tokonoma regions; no baked-in movable decor.
- The final example mock demonstrates possibilities but is not a canonical solution.

## Learning integrity

Decoration never grants mastery, money or plant growth. Those rewards continue to come only from demonstrated learning.
