## W1. Replace the throwaway options

Every cloze has one real near-miss and two options nobody would ever pick, so
four choices behave like two. A learner can score 50% by eliminating nonsense.

The rule I used: **every option should be something a person could plausibly do
in that room.** The learner should have to know the word, not spot the joke.

### 0. 揃える - two cushions facing the same way on each mat

| | now | proposed | why |
|---|---|---|---|
| correct | 揃えて | 揃えて | |
| near-miss | 揃って | 揃って | the transitive/intransitive pair, the real point |
| | 片付けて | **並べて** | to lay out in a row - very close, but says nothing about matching |
| | 散らかして | **重ねて** | to stack them - a real thing to do with cushions |

### 1. 取り替える - dirty sheet into the basket, new sheet on

| | now | proposed | why |
|---|---|---|---|
| correct | 取り替えて | 取り替えて | |
| near-miss | 代えて | 代えて | |
| | 洗って | 洗って | keep - washing a dirty sheet is plausible, just not now |
| | そのままにして | **裏返して** | to turn it over - the lazy shortcut a real person might take |

### 2. 温める - cold rice, microwave

| | now | proposed | why |
|---|---|---|---|
| correct | 温めて | 温めて | |
| near-miss | 温まって | 温まって | |
| | 焼いて | 焼いて | keep |
| | 冷やして | **蒸して** | to steam - a genuine way to reheat rice |

### 3. 調整 - two groups want the same dinner time

| | now | proposed | why |
|---|---|---|---|
| correct | 調整して | 調整して | |
| near-miss | 調節して | 調節して | |
| | 中止して | **変更して** | to change it - close, but 調整 is reconciling *conditions* |
| | 放置して | **確認して** | to check - what you would do first, but not what was asked |

### 4. 引き受ける - tomorrow's breakfast service

The existing set is all 引く compounds, which teaches the family. But 引き返す
and 引き出す make no sense with 配膳, so they are eliminable without knowing
anything.

| | now | proposed | why |
|---|---|---|---|
| correct | 引き受けて | 引き受けて | |
| near-miss | 引き止めて | 引き止めて | keep one compound, so the family is still tested |
| | 引き返して | **手伝って** | to help - plausible and nearly right, but weaker than taking it on |
| | 引き出して | **代わって** | to take someone's place - very close, different relationship |

**Audio cost: none.** Options are read, never spoken.

## W2. Two more situations for 引き受ける

Today all three days use the same accept/decline errand screen, so its review
ladder shows one learner the same screen twice.

### Situation B - the entrance in the morning

- narration: `コン：「明日の朝、玄関を開ける前に掃除が要ります。私は朝食の支度がありますので、一人では回りません。」`
- request: `明日の朝、玄関の掃除を引き受けていただけませんか。`
- success: `ありがとうございます。これで朝のお客様を気持ちよくお迎えできます。`

### Situation C - the futon before the guests return

- narration: `コン：「お客様は花火を見に出かけました。戻るまでにお布団を敷いておきたいのですが、部屋が六つあります。」`
- request: `三番から六番のお部屋のお布団を引き受けていただけませんか。`
- success: `ありがとうございます。お客様が戻るまでに間に合いました。`

**Audio cost: 6 clips** (narration, request and reply for each).

## C5. Day 3 asks 温める and 引き受ける by name

These two are answered by working the room today, which proves nothing:
温める turns on food-versus-room, and 引き受ける is a decision, not an action.
引き受ける's screen is two buttons, so the final test can be passed on a coin
flip. Both should be listening questions instead - the format Episode 1 uses.

### 温める

- spoken: `お客様：「このスープ、冷めてしまいました。」` **(new clip)**
- asked: `何をしますか。`

| | option | note |
|---|---|---|
| correct | 温めます。 | |
| near-miss | 暖めます。 | rooms and air, not food - the actual N2 distinction |
| near-miss | 温まります。 | it becomes warm by itself |
| | 冷やします。 | the opposite |

### 引き受ける

- spoken: `コン：「明日の朝、駅までお客様を送る仕事があります。お願いできますか。」`
  **(already recorded - this is Day 3's current line, and it does not contain
  the answer, so it can be reused as-is)**
- asked: `何と答えますか。`

| | option | note |
|---|---|---|
| correct | はい、引き受けます。 | |
| near-miss | はい、受け取ります。 | to receive an object, shares 受ける |
| | はい、引き止めます。 | to stop someone leaving |
| | はい、引き返します。 | to turn back |

**Audio cost: 1 clip.** The 引き受ける prompt already exists.

## W3. A different shift shape each day

Both days currently walk the same order - cushions, cloth, something cold, the
schedule, tomorrow's favour - so the second day feels like the first repeated.
The order cannot simply be shuffled: each narration is tied to its own task and
an earlier shuffle made a day jump from after dark to the next morning.

So Day 2 gets a different shift: it starts in the office with tomorrow's plan
and works outward, instead of starting with the cushions again.

**Proposed Day 2 order:** 調整 → 温める → 揃える → 取り替える → 引き受ける

- 調整: `コン：「二日目は帳場から始めます。今夜はCグループとDグループが同じ時刻をご希望です。食事処は一組ずつしかご案内できません。」`
- 温める: `コン：「時刻が決まりました。厨房を見てきてください。早く着いたお客様の分のごはんが冷めています。」`
- 揃える: `コン：「食事処を開けます。前の組が使った座布団が、向きばらばらのままです。」`
- 取り替える: `コン：「お食事の間に客室を回ります。三番のシーツに染みがついていました。」`
- 引き受ける: `コン：「今日はよく回りました。最後にもう一つ、明日の朝食の配膳をお願いしたいのですが。」`

**Audio cost: 5 clips.**
